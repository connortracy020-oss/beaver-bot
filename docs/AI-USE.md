# AI use disclosure

This project is a student class project. The course requires disclosing AI use. This file lists what was
AI-assisted and what was done by the student. **Keep it updated whenever AI is used.** Add a dated line to the log
at the bottom.

## Tools

- **Claude Code** (Anthropic), running in the Claude desktop app on the student's laptop, model **Claude Opus 5.5**
  (the site build on 2026-11-09 ran on **Claude Fable 5.2**, the model the student selected for it).
- **Claude Haiku 5.5** through Anthropic's API, as the model that writes Beaver Bot's answers, from 2026-11-09 on
  the student's instruction. It receives only public page excerpts and the question with contact details and ID
  numbers removed. The site also runs with no model at all (the default).
- Claude Code also ran **sub-agents** (other Claude instances) to review code and data quality. These reviews were read-only and offline.
- Claude Code used **web search** to locate OSU's own policy pages (acceptable use, trademark, the retired A–Z index).
- All crawling of OSU sites was done by this project's crawler (`osu_crawl/`), never by an AI tool fetching pages directly.

## What the AI did *not* do

- It did not log in anywhere, submit forms, or call OSU APIs. The site build sent no requests to OSU at all.
- It did not train any model on the crawled data, and the data stays local.
- Before 2026-11-09 no crawled text was sent to any model API. Since then, with the student's approval, short
  excerpts of public pages are sent to Anthropic's API when the Claude provider is turned on. Nothing else is
  sent: no student records exist in this project, and questions have contact details and ID numbers removed.
- It did not push the repository anywhere, deploy the site, or commit the site build.
